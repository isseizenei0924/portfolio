## 学んだこと

### ツールの使い分け
| ツール | 用途 |
|--------|------|
| Cursor | AI補完付きエディタ |
| Claude Code | ターミナルエージェント（ファイル操作できる） |
| Codex CLI | OpenAI製ターミナルエージェント |
| claude.ai | コード以外の質問・調べもの |

### ローカル vs クラウド
- Claude Code / Codex CLIはローカル実行（コードはPC上に置いたまま）
- AIの思考部分だけクラウドで処理される

### コンテキスト上限対策
- 上限が近づいたらClaude Codeに「CLAUDE.mdにまとめて」と頼む
- `/clear`でリセットしてもCLAUDE.mdは自動で読み込まれる

### mdファイルの使い方
- `CLAUDE.md` → プロジェクトの基本情報（自動読み込み）
- `docs/` → 作業ログ・コマンドメモ・引き継ぎ情報
- `docs/memo/` → claude.aiの会話まとめ・雑多なメモ
- ファイル名は日付+内容で管理 → `2026-03-16_github入門.md`

## 基本コマンド

### Claude Code
```bash
claude        # 起動
/clear        # 会話リセット
Ctrl + C      # 終了
```

### Git
```bash
git status                    # 状態確認
git add .                     # 変更をまとめる
git commit -m "メッセージ"    # セーブポイント作成
git push                      # GitHubにアップロード
```

### Git初回設定
```bash
git config --global user.email "メールアドレス"
git config --global user.name "isseizenei0924"
```
