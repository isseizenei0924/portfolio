# Portfolio

個人ポートフォリオサイトです。

## サイト構成

```
portfolio/
├── index.html        # メインページ
├── assets/
│   ├── css/          # スタイルシート
│   ├── js/           # JavaScript
│   └── images/       # 画像
└── docs/
    ├── dev-log/      # 開発ログ
    └── reference/    # コマンドリファレンス
```

## 使用技術

- HTML
- CSS

## ローカルで確認する

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。
